# Best Move

A static workout planner and tracker.

## Features

- Choose from Upper body, Lower body, Push, Pull, Legs, and Fullbody routines.
- Track workout progress and rest time.
- Review workout history in the calendar.
- Calculate BMI using weight in kilograms and height in centimeters.

## Run locally

Open a terminal in this folder and run:

```powershell
py -m http.server 4173
```

Then open <http://localhost:4173/> in a browser.

## Data storage

This demo stores accounts and workout records in the browser's local storage. Data stays in that browser and does not sync between people or devices. The sign-in screen is for local demo use, not production authentication.
